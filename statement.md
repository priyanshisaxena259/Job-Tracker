# Job-Tracker – Job and Application Tracking System

## 1. Problem Statement

Managing multiple job opportunities and applications manually can become difficult for candidates.

A candidate may need to keep track of different job postings, application statuses, interview schedules, job deadlines and other application related information.

JobTracker provides a simple console-based system for organizing job opportunities, applications and interviews in one place.

---

## 2. Objectives

The main objectives of the JobTracker project are:

- To provide a simple system for managing job opportunities.
- To maintain and track job applications.
- To track the status of applications.
- To manage interview schedules.
- To allow users to search and retrieve job information.
- To generate application statistics and reports.
- To demonstrate Core Java and Object-Oriented Programming concepts.
- To provide persistent storage using Java file handling.

---

## 4. Scope of the Project

The scope of JobTracker includes:

- Managing job postings.
- Adding, viewing, searching, updating, and deleting jobs.
- Creating and managing job applications.
- Tracking application statuses.
- Scheduling and viewing interviews.
- Storing job, application, and interview information using local text files.
- Generating application statistics.
- Generating a text-based project report.

The project focuses on demonstrating Core Java concepts through a practical job and application management system.

---

## 5. Target Users

### Job Seekers / Candidates

Candidates can use the system to:

- Keep track of available jobs.
- Record their job applications.
- Track application progress.
- Store interview information.
- Review application statistics.

### Students / Learners

The project can also serve as an educational example for students learning Java, Object-Oriented Programming, file handling, collections, exception handling and multithreading.

---

## 6. High-Level Features

### Job Management

- Add jobs.
- View all jobs.
- Search jobs by title or location.
- Find jobs using their ID.
- Update job details.
- Delete jobs.

### Application Management

- Create job applications.
- View applications.
- Find applications using their ID.
- Update application status.
- Delete applications.

### Interview Management

- Schedule interviews.
- View scheduled interviews.
- Store interview date and time.
- Store interview type.
- Store meeting links.

### Reporting

- View application statistics.
- Count applications based on status.
- Generate a text-based report.
